# 🎯 Algoritmo — Jogo de Adivinhação

## 📌 Descrição

O algoritmo define as etapas necessárias para desenvolver um jogo de
adivinhação de números utilizando Python.

O programa solicita ao usuário um intervalo numérico, gera um número
aleatório dentro desse intervalo e permite que o usuário tente descobrir
o número dentro de uma quantidade limitada de tentativas.

---

## 🔄 Etapas do algoritmo

### 1. Definir o intervalo

O usuário informa:

- Limite inferior
- Limite superior

Exemplo:

```text
Limite inferior: 1
Limite superior: 100
