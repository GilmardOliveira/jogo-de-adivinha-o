# 🎯 Jogo de Adivinhação em Python

Um jogo simples de adivinhação desenvolvido em Python como projeto de estudo para praticar lógica de programação e conceitos básicos da linguagem.

## 📌 Sobre o projeto

O programa solicita ao usuário um limite inferior e um limite superior para definir um intervalo numérico.

Em seguida, o Python gera um número aleatório dentro desse intervalo e o usuário precisa tentar descobrir qual foi o número escolhido.

Durante o jogo, o programa informa se o palpite foi maior ou menor que o número secreto.

## 🧠 Conceitos praticados

- Variáveis
- Entrada de dados com `input()`
- Conversão de tipos
- Estruturas condicionais `if`, `elif` e `else`
- Estrutura de repetição `while`
- Geração de números aleatórios
- Módulo `random`
- Módulo `math`
- Logaritmos
- Controle de tentativas
- Lógica de programação
